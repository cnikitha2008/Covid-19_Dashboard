# COVID-19 Dashboard

An interactive COVID-19 data analysis dashboard built using Python, Pandas, NumPy, Matplotlib, and Streamlit.

## Modules

1. Data Management
2. Worldwide Analysis
3. Country/State/Regional Analysis
4. Time Series Trends
5. Statistical and Distribution Analysis
6. User Interface and Navigation

## Dataset

COVID-19 time-series dataset from the datasets GitHub repository.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Streamlit
